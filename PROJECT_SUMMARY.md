MeshWeaver: Zero-Dependency P2P Async Task BrokerMeshWeaver is a pure-Python, zero-dependency peer-to-peer asynchronous task broker. It enables distributed nodes to discover each other, exchange tasks, and execute them asynchronously over a mesh network — without relying on any external packages, message queues, or central brokers.

Key Features

- Zero dependencies — Built entirely with Python’s standard library
- Peer-to-Peer architecture — No central server required
- Fully asynchronous — Non-blocking task distribution and execution
- Mesh networking — Nodes automatically form a resilient, self-organizing network
- Lightweight & portable — Runs anywhere Python is available

Ideal For

- Distributed computing experiments
- Edge / IoT task distribution
- Lightweight job queues in constrained environments
- Learning and prototyping P2P systems without heavy frameworks
