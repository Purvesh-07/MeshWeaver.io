# MeshWeaver

Zero-Dependency P2P Async Task Broker

Features

- UDP peer discovery
- Kademlia DHT
- Gossip metrics
- Remote task execution
- Failure recovery
- Replay protection
- CLI
- Dashboard

Examples

python examples/ping_demo.py
python examples/spawn_mesh.py
python examples/remote_demo.py
python scripts/chaos.py
python examples/tls_demo.py
python -m meshweaver --help
